    本模块做什么
    
    
      
  • 环境检测：KernelSU / Root / Bootloader / SELinux / 完整性 / 模块列表 / Hook·Overlay·注入痕迹
    • 
      
  • 游戏兼容模式：临时停用指定模块（可恢复、有备份、可超时自动恢复），减少其他 Root 修改对游戏环境的干扰
    • 
      
  • 诊断：游戏运行期间记录进程起止、模块状态、SELinux、系统属性变化，生成关联性报告
    • 
    

  

  

    本模块绝不做什么
    
    
      
  • 不绕过/欺骗反作弊、不伪造认证、不隐藏游戏进程
    • 
      
  • 不 Hook/Patch 反作弊组件、不修改游戏文件/内存
    • 
      
  • 不自动点击/自动瞄准、不绕过账号处罚
    • 
      
  • 不修改 SELinux（只读状态）
    • 
    

  

  

    必须知道的边界
    
    
      
  • 模块停用标志重启后完全生效（脚本与挂载不再加载）；不重启时仅结束相关进程
    • 
      
  • 解锁 Bootloader + Root 本身就可能被游戏检测到，本模块无法也不打算隐藏这一点
    • 
      
  • 诊断报告只提供关联性提示，不证明因果关系，更不保证能定位冻结原因
    • 
      
  • 冻结判定发生在服务器侧，客户端观测不到依据
    • 
    

  

  

    命令行备用（当 WebUI 命令执行不可用时）：

    su -c gs.sh env · su -c gs.sh game on · su -c gs.sh diag start · su -c gs.sh diag report
